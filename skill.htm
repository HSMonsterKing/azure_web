個人技能樹

SQL Server Analysis Services (SSAS)

用於建立多維度資料模型與 OLAP 分析環境， 可將企業資料倉儲轉換為高效能分析模型。 主要應用於商業智慧 (BI) 系統， 提供快速的資料查詢與分析能力。

SQL Server Reporting Services (SSRS)

微軟的企業報表平台， 用於建立企業級報表與定期報表系統。 可以與 SQL Server 整合， 提供自動化報表產生與資料視覺化功能。

Power BI

Microsoft 商業智慧分析平台， 可將資料轉換為互動式儀表板與視覺化報表。 常用於企業 KPI 監控、銷售分析與營運分析。

DAX 開發

DAX (Data Analysis Expressions) 是 Power BI 與 Analysis Services 使用的資料分析語言。 主要用於建立計算欄位、度量值 (Measures) 以及複雜的商業邏輯計算。

Python 開發

使用 Python 進行資料處理、自動化與資料分析， 常搭配 Pandas、NumPy 等資料分析工具。 也可用於 ETL 流程開發與資料清理。

Azure SQL Database 建置

Microsoft Azure 雲端資料庫服務， 可建立高可用性的雲端資料平台。 適用於雲端應用程式與企業資料系統， 並可與 Power BI 與 Azure Data Services 整合。
